# Pranesh T's portfolio

The static entry point is index.html. Serve the repository root to preview the site.

Run npm ci and npm run build after editing the React sections in src/cinema, the data in src/content.js or src/cinema/site.css. The build produces Assets/JS/cinema.js and Assets/CSS/cinema.css.

Layout and scroll interactions are adapted from https://github.com/lohithadamisetti123/cinematic-portfolio. The walking illustration, MP4, portraits and project content are personalized for Pranesh T. Font licenses are in Assets/fonts.
